## Maker comment

Hi, I built Agent Hub for work that ends up spread across coding clients.

A useful decision can be buried in a chat you no longer remember by name. When you switch clients, you end up finding it again and explaining the task from scratch.

Agent Hub gives you one local place to save and search supported chats from Claude Code, Codex CLI and DeepSeek Harness. Open the original messages, choose “Continue in…” and review the context before copying it into a new conversation. The original chats stay where they are. You can also keep the selected sources updated in the background.

This is context for a new chat, not the exact running state of another client. Hub prepares original excerpts with references; it does not make an extra AI summary request or provide a model. Supported local files are preserved, while unavailable attachments and incomplete sources are marked.

The tool also offers reviewed sharing of MCP settings, skills and instructions. We're keeping those setup actions separate from archive updates.

It's open source and runs locally. The current install needs Node.js 22.13+ and npm. macOS and Linux are supported; Windows is experimental.

I'm testing a simple question: does this save you work compared with your current history search, Markdown notes or another manager? If you try it, tell me which task you completed and what got in the way. Please keep private transcripts and credentials out of public feedback.
